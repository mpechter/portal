Frequently Asked Questions

What Airtable plan do I need?

Any Airtable plan works, including the free plan. Free plans allow 1,000 API calls per month — enough for small or low-traffic portals. Team plans allow 100,000 calls per month, which suits most active portals. Each client page load uses a small number of API calls.

Does Airbud store my Airtable data?

No. Your data lives in Airtable. Airbud reads it on demand to display to your clients and never copies or caches it.

What does Airbud store?

Your Airtable API key, base configuration, field settings, and client login info (email addresses and login codes). Nothing else.

Is my API key safe?

It's stored securely and only used to fetch your data. We never share it.

How do I know how many API calls I've used?

On the Free plan, usage is visible in your workspace settings. See Airtable's documentation for where to find it. On Team plans and above, Airtable does not provide granular API usage tracking.

Do my clients need an Airtable account?

No. They just log in with their email address — no Airtable account, no passwords.

How does client login work?

Clients receive a one-time code and magic link via email. One click and they're in.
